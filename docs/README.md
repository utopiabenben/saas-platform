## V3.0 本次补齐

- 统一身份：AccountIdentity、Session、账号安全。
- 多租户：Tenant、Workspace、Membership、RBAC。
- 多应用：Application、TenantApp、应用授权。
- SaaS 商业化：Plan、Feature、Price、Subscription、订单、支付、退款、发票。
- 账户体系：现金钱包、积分、AI 使用额度、功能权益，独立账本。
- 计量体系：Token、调用次数、任务、存储、席位及配额控制。
- 双分销体系：SaaS 渠道分销与业务商品推广分开建模。
- 运营能力：平台后台、租户后台、个人账户中心、渠道工作台。
- 可靠性：租户隔离、幂等、Outbox/Inbox、Webhook 重试、审计和验收用例。

**当前产品基准：V3.0。** V2.0 保留，不覆盖历史设计。
