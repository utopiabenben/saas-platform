# 需求简述｜SaaS 底座 · 权益中台

> 版本 **V2.0** · 日期 2026-11-20  
> 对应完整方案：[`方案-SaaS底座-权益中台-V2.0.md`](./方案-SaaS底座-权益中台-V2.0.md)

---

## 1. 要解决什么问题

建设一套**可私有部署、可多产品接入**的 SaaS 底座：

1. **平台内核**：谁登录、属于哪家客户（租户）、什么角色。  
2. **权益模块**：一级分销归因与佣金月结、终端分享积分与兑换。  
3. **业务解耦**：首个接入方为 AI Smart 儿童英语；学习主线不进底座。

一句话：**底座管身份与租户；权益管分钱与积分；业务 App 经 SSO + 订单事件接入。**

---

## 2. 目标用户与角色

| 角色 | 归属 | 核心诉求 |
|------|------|----------|
| 平台超管 `platform_admin` | 跨租户 | 开/停租户、全局审计 |
| 租户管理员 `tenant_admin` | 租户内 | 费率、月结审核、礼品履约、开通 Partner |
| 经营者 `partner` | 租户内 Membership 角色 | 专属链接、货架、佣金与月结收款 |
| 终端用户 `end_user` | 租户内 Membership 角色 | 购课、分享得积分、兑权益/礼品 |

硬约束：

- **账号 Account** 全局唯一登录；**角色挂在 Membership**，不挂在 Account 全局。  
- 同一人可在租户 A 是 Partner，在租户 B 只是 EndUser。  
- Partner **不可见**儿童学习明细。  
- 默认 **一级分销**；终端分享 **只积不佣**（与提成互斥策略可配）。

## 3. 功能需求（按优先级）

### P0｜底座可登录 + 能卖能算清

- [ ] Tenant / Account / Membership / JWT 租户上下文  
- [ ] 开租户、注册 Tenant App（首个：`ai-smart-english`）  
- [ ] Partner 邀请码 + 归因 Cookie + `/p/:code` 货架  
- [ ] `order.paid` / `order.refunded` → 佣金账本（默认 30%×实付）  
- [ ] 退款冷静期 + 月结单生成（打款可人工）  
- [ ] Partner 台：预估 / 明细 / 月结  

**验收**：测试租户下两单（一退一留），月结金额正确；无 `tenant_id` 请求拒绝；货架页只展示所选课。

### P1｜C 端裂变 + 履约

- [ ] 分享积分规则 + 不可变流水 + 虚拟权益兑换  
- [ ] `reward.granted` Webhook 回写业务 App  
- [ ] 防刷（日上限、设备/IP）  
- [ ] 租户后台配置积分规则与兑换目录  

**验收**：分享→注册→积分入账；兑换后 App 侧权益生效。

### P2｜多租户可售卖

- [ ] 超管开/停租户；API Key / 密钥轮换  
- [ ] 打款导出、实物礼品、对账报表  
- [ ] Partner 申请审核、多费率模板  
- [ ] 第二款业务 App 接入文档  

**明确不做（除非单独立项）**：多级分销、经营者改价、底座内嵌学习引擎。

---

## 4. 业务规则（摘要）

| 规则 | 约定 |
|------|------|
| 一单一归属 | 有 `partner_id` → 提成；无 → 归租户/平台 |
| 提成基数 | 订单实付（不含运费） |
| 默认佣金率 | 30%（可租户默认 / Partner 覆盖） |
| 冷静期 | 建议 7～15 天，过完才可入月结 |
| 归因窗 | Cookie TTL 建议 7～30 天 |
| 积分账本 | earn / redeem / expire / adjust；禁止直接改余额 |
| 数据隔离 | 全业务表带 `tenant_id`；跨租户读应 404 |

---

## 5. 非功能需求

- 技术栈：NestJS + PostgreSQL + Redis（队列预留 BullMQ）  
- 鉴权：底座签发 JWT；业务 App SSO 或同父域 Cookie  
- 幂等：支付/退款/兑换必须带幂等键  
- 审计：佣金与积分调整记操作者  
- 部署：可私有化；首版共享库 + `tenant_id` 逻辑隔离  

---

## 6. 首个业务场景

**租户应用：** AI Smart 儿童英语  

- 学习主线（L 等级、测评、周报）留在业务 App。  
- 底座只接收：`user.registered` / `order.paid` / `order.refunded` /（可选）`share.click`。  
- 底座回写：`reward.granted`（虚拟权益履约）。
