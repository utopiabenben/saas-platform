## 1. 要解决什么问题

为 ShareDAO、AI Smart 儿童英语、数字商品商店、出口认证及未来业务，提供统一的：

- 身份与组织、应用目录、套餐订阅、订单支付  
- 账户与权益（现金/积分/额度/功能权益分账本）  
- 用量计量、渠道分销、佣金结算、开放接入  

业务应用只负责自身业务对象与履约；经 SSO + 标准事件接入中台。

**硬边界：** 登录账户、租户订阅、现金钱包、积分、AI 额度、功能权益、分销佣金是不同账本，禁止混用一个 balance。

---

## 2. 核心对象

| 对象 | 说明 |
|------|------|
| Account + AccountIdentity | 全局登录；手机/邮箱为 Identity，非 Account 主键 |
| Tenant / Membership | 客户隔离；角色挂 Membership |
| Application / TenantApp | 产品目录与租户开通实例（禁止 Tenant.plan 单字段） |
| Plan / Subscription | 套餐定义与购买实例 |
| ChannelPartner vs AffiliatePartner | SaaS 渠道销售 vs 业务商品推广，表与状态机分离 |

---

## 3. 分期

### P0｜统一身份与租户底座
AccountIdentity、Session、Tenant、Invitation、RBAC、Application、TenantApp、Webhook/Outbox、审计与多租户隔离。

### P1｜产品商业化闭环
Plan/Feature/Price、Subscription、Billing/Payment/Refund、Entitlement、UsageCredit、用量计量。

### P2｜积分与双线分销
Points 兑换履约；Channel + Affiliate 佣金与结算。

### P3｜规模化（后置）
多币种税区、渠道层级、私有化授权、运营分析。

---

## 4. 上线门槛（摘要）

- TEN-001/002：双租户 Membership 与跨租户拒绝  
- IAM：邀请与禁用会话失效  
- APP-001：一租户开通多应用  
- BILL/WAL/USG：支付幂等、额度不超扣、用量去重  
- CHN/AFF：两类佣金互不串表
